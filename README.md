Bootstrap Resampling using Python

Project Overview

This project demonstrates Bootstrap Resampling, a statistical technique used to estimate sampling distributions and confidence intervals.

Features

- Bootstrap Confidence Interval for Mean
- Bootstrap Confidence Interval for Median
- Bootstrap Hypothesis Testing
- Comparison with Parametric T-Test
- Data Visualization

Technologies Used

- Python
- NumPy
- SciPy
- Matplotlib
- Jupyter Notebook

Installation

pip install numpy scipy matplotlib jupyter

How to Run

1. Clone the repository.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run all cells.
